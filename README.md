Este é um projeto de estudos desenvolvido em Python, focado em ferramentas de criptografia e segurança de dados. O objetivo é compreender na prática como funcionam algoritmos de hash, criptografia simétrica e assimétrica, além de técnicas de armazenamento seguro de senhas.

### Sobre o projeto
Este projeto foi criado com base no tutorial **"Cryptography for Beginners - Full Python Course"** do canal *freeCodeCamp.org*. A ferramenta implementa um CLI (interface de linha de comando) que permite ao usuário realizar diversas operações de segurança.

### Funcionalidades
* **Hashing de arquivos:** Verificação de integridade usando SHA-256.
* **Criptografia Simétrica:** Implementação de AES (Advanced Encryption Standard) para cifrar e decifrar dados.
* **Criptografia Assimétrica:** Implementação de RSA com par de chaves pública/privada.
* **Gerenciador de Senhas:** Verificação de força de senhas (usando `zxcvbn`) e hashing seguro para armazenamento (usando `bcrypt`).
